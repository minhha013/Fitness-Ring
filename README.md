# Smart Fitness Ring

A low-cost smart fitness ring designed to make basic health tracking more accessible. This project focuses on developing a compact wearable device capable of tracking biometrics such as steps, heart rate, and Basal Metabolic Rate (BMR) without the high price tag or recurring subscription costs often associated with commercial fitness wearables.

The motivation behind this project is simple: health is important, and people should be able to stay informed about their bodies without having to spend large amounts of money. I wanted to explore how a custom-built solution could provide useful health insights in a sleek, wearable form factor while remaining affordable and practical.

This project combines custom flex PCB design in KiCad, mechanical design in SolidWorks, and software development for data storage and visualization. By integrating hardware, enclosure design, and app development into one system, this project represents a full-stack wearable engineering effort centered on accessibility, affordability, and health awareness.

## Features
- Custom two-layer flex PCB
- Step tracking
- Heart rate monitoring
- Basal Metabolic Rate (BMR) estimation
- Compact ring enclosure designed in SolidWorks
- Companion app for storing and visualizing data

## Tech Stack
- **PCB Design:** KiCad
- **CAD Modeling:** SolidWorks
- **Hardware:** Custom wearable electronics and sensors
- **Software:** Companion app development
