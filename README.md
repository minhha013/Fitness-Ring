# Smart Fitness Ring PCB

This branch contains the PCB design files for the Smart Fitness Ring project, a low-cost wearable device designed to track basic biometrics such as steps, heart rate, and Basal Metabolic Rate (BMR). The purpose of this branch is to document the electrical design and hardware development process behind the custom ring electronics.

The PCB is being developed to support a compact and wearable form factor while integrating the key sensing and processing components needed for health tracking. Because the ring is intended to remain small, lightweight, and practical, the PCB design requires careful consideration of size constraints, component placement, routing, and power management.

## Purpose

The goal of this PCB design is to create a reliable and compact hardware platform that can serve as the foundation for an affordable fitness ring. Many commercial smart rings are expensive and often require subscription fees, which can make health tracking less accessible. This project aims to explore how a custom-designed solution can provide useful biometric tracking at a lower cost.

## PCB Features

- Custom PCB designed in KiCad
- Intended for integration into a compact smart ring
- Supports step tracking functionality
- Supports heart rate sensing
- Supports BMR estimation through collected biometric data
- Designed with wearable size constraints in mind

PCB design in progress.
